Пути в линукс: 
1) /etc - обычно в этих каталогах лежат конфиг файлы наших сервисов
2) /var - каталог для переменных данных, типа логов
3) /opt - каталог в котором обычно лежать стороние скрипты
4) /proc - информация про сервер
5) /dev - каталог с блочными устройствами, по сути с дисками в серваке и их логическими томами

Команда ss — это инструмент, используемый для вывода сетевой статистики в виде, похожем на тот, который выдаёт команда netstat. Однако, ss делает это проще и быстрее
ss - выведет информацию о всех работающих соединений
ss -l - выведет сокеты ожидающие соединения
-t - показывает TCP
-u - показывает UDP
-x -показывает  UNIX соединения
также эта команда может филтровать по определенным состояниям, адресам

BASH
В начале файла #!/bin/bash
По сути баш это тоже самое что и консоль, просто команды оформлены в файл
1) Чтобы присвоить переменную надо:
переменная=значение
напрмиер 
a=54

Чтобы потом вызвать это значение надо исползовать $
echo "$a силен" выведет "You силен"

Также если есть встроенные переменные то можно их использовать например $HOME

Разница между " и '
Двойные кавычки позволяют подставлять переменные, а одинарные замораживают текст


Ввод команд можно двумя способами или обратными кавычками или через $
mydir=`pwd`
mydir=$(pwd)

Для математических операций требуются двойные скобочки
var1=$(( 5+5 ))
var2 = $(( $var1 + 10 ))

Условия if then fi
if команда //если завершится успешно то выполнится условие then
then
команда
fi //просто заканчивает условие

Session 4
1) cd - переход в  каталог
cd /var
2) ss - посмотреть какие порты и чем слушаются
ss -tulp
3) ip a - посмотреть ip хоста, какие есть интерфейсы
4) tail - посмотреть последние n строк
tail -n 1000 /var/log/syslog
6) cat - вывести содержимое файла
cat test
7) nano - редактор файла
nano test
8) echo - выводит сообщение в терминал
echo "PUP"
9) >, >>, | - потоки вывода: одна стрелка перенаправить в файл и перезаписать, две перенаправить в файл и добавить это в конец, пайл перенаправить вывод одной команды  в другую
10) man - инструкции по командам
man ls
11) kill - поcылает сигналы процессам
kill -9 python
12) ssh - удаленное подключение к хосту
ssh IP
13) ls -la - вывод содержимого директории -l подробный вывод, -a - вывод скрытытх файлов
14) head - вывести первые строки файла
head /var/log
15) mount - смонтировать диск
mount sda
16) chmod - изменние прав каталога\директории
chmod 777 test
17) grep - фильровать вывод команд
cat test | grep error
18) apt - менеджер пакетов
apt install
19) history - посмотреть предыдущие команды введеные в терминал
20) find - искать по ОC
find / -name test
