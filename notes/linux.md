Пути в линукс: 
1) /etc - обычно в этих каталогах лежат конфиг файлы наших сервисов
2) /var - каталог для переменных данных, типа логов
3) /opt - каталог в котором обычно лежать стороние скрипты
4) /proc - информация про сервер
5) /dev - каталог с блочными устройствами, по сути с дисками в серваке и их логическими томами

Sessions3
Команда ss — это инструмент, используемый для вывода сетевой статистики в виде, похожем на тот, который выдаёт команда netstat. Однако, ss делает это проще и быстрее
ss - выведет информацию о всех работающих соединений
ss -l - выведет сокеты ожидающие соединения
-t - показывает TCP
-u - показывает UDP
-x -показывает  UNIX соединения
также эта команда может филтровать по определенным состояниям, адресам

BASH
В начале файла #!/bin/bash
По сути баш это тоже самое что и консоль, просто команды оформлены в файл
1) Чтобы присвоить переменную надо:
переменная=значение
напрмиер 
a=54

Чтобы потом вызвать это значение надо исползовать $
echo "$a силен" выведет "You силен"

Также если есть встроенные переменные то можно их использовать например $HOME

Разница между " и '
Двойные кавычки позволяют подставлять переменные, а одинарные замораживают текст


Ввод команд можно двумя способами или обратными кавычками или через $
mydir=`pwd`
mydir=$(pwd)

Для математических операций требуются двойные скобочки
var1=$(( 5+5 ))
var2 = $(( $var1 + 10 ))
