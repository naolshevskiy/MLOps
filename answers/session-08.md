# Сессия 8 — ответ на вопрос дня

**Вопрос:** Что такое слой образа и почему порядок строк в Dockerfile важен?

Слой образа — это неизменяемый срез файловой системы, который хранит только разницу (изменения, новые файлы) относительно предыдущего слоя.
Docker-образ собирается из таких слоев, как пирог.
Порядок строк в Dockerfile важен по двум причинам:
Скорость сборки (кэширование): Docker собирает образ сверху вниз. Если строка изменилась, кэш для нее и всех последующих строк сбрасывается. Поэтому редкие и тяжелые операции (установка библиотек) ставят наверх, а частые (копирование кода) — вниз.
Размер образа: Каждый слой фиксирует состояние. Если скачать файл в одной строке, а удалить в другой, он все равно останется в истории и займет место. Для экономии файлы скачивают и удаляют внутри одной строки RUN через &&.
